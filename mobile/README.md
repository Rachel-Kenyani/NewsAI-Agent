# News AI Mobile Project

This directory contains the mobile application for the News AI Agent.

## Project Structure

- `news_app/`: The primary Flutter project.
  - `lib/models/`: Data models and Pydantic-like structures.
  - `lib/screens/`: UI screens and pages.
  - `lib/services/`: API services and business logic.
  - `lib/widgets/`: Reusable UI components.

## Getting Started

1. Ensure you have the Flutter SDK installed.
2. Navigate to the `news_app` directory:
   ```bash
   cd news_app
   ```
3. Fetch dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```
